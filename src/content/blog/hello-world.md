Welcome to my blog. I built this site with [Astro](https://astro.build) and
it's published automatically to [GitHub Pages](https://pages.github.com/)
whenever I push to the `main` branch.

## Why a blog

I wanted a simple, fast place to write about what I'm building and learning,
without fighting a CMS or a heavyweight framework. Astro ships zero JavaScript
by default, the content lives in plain Markdown files right next to the code,
and deployment is a single GitHub Actions workflow.

More posts to come.
